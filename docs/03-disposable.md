# КТ №42. Финализируемые объекты. IDisposable. using


https://kili.ru/screen/r/4mikVPNQh7NbdcRQabumyS5C

Главное различие между IDisposable и финализатором заключается в том, кто и когда освобождает ресурсы.

При использовании IDisposable программист сам контролирует время жизни объекта, мгновенно закрывая ресурс при выходе из блока using. Финализатор запускается сборщиком мусора (GC) автоматически в неизвестный момент, когда программе начинает не хватать памяти. Поэтому IDisposable используется для быстрой и штатной очистки любых ресурсов, а финализатор служит лишь запасной страховкой для неуправляемых ресурсов и замедляет сборку мусора.
